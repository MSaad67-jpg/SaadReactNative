# SaadReactNative

A basic React Native project created as part of Mobile Application Development Assignment 1.

## Technologies Used
- React Native
- JavaScript
- Node.js
- Android Studio
- Visual Studio Code

## Setup Instructions

Install dependencies:

```bash
npm install
```

Start Metro:

```bash
npm start
```

Run the Android application in another terminal:

```bash
npm run android
```
